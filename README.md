## Publish to GitHub Pages

1. Upload the **contents of this folder** (not the folder itself) to the root of the `shahzadms7.github.io` repository.
2. In the repo: **Settings → Pages → Source: `main` / root**.
3. Live within a minute at **https://shahzadms7.github.io/**. (`.nojekyll` is included so the `assets/` folder serves correctly.)
