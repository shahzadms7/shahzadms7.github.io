# Single-page portfolio redesign — 1 September 2026

Built and locally verified for publication through a dedicated branch and pull request in this portfolio repository. Changes are limited to this repository.

Includes six anonymized engagement summaries, 41 resume-derived project families, 15 technology domains, delivery workflow, services, career progression, career-scale context and direct contact routes. Historical solution URLs redirect into the single page. A navy, warm-white and teal design uses system fonts and local assets.

Browser checks passed at 360, 390, 768, 1024 and 1440 pixels with no horizontal overflow. Search, empty results, reset, category filtering, expand/collapse, disclosures, mobile navigation, Escape dismissal, no-JavaScript reading and a legacy redirect passed. No page JavaScript errors or external page-load requests were observed. Automated axe WCAG 2 A/AA and 2.1 AA scan reported no violations; this is not a complete accessibility certification.

Content was derived from the current resume and owner clarification. Confidential names were excluded. Selected client-specific counts, ambiguous global usage and unverified product/version wording were generalized or withheld. All 41 families and 15 core skill domains are represented; this does not certify every historical keyword or external product claim. Credentials are available by request rather than publishing examination plans as earned qualifications.

Release procedure: review the dedicated branch, merge the pull request, then verify GitHub Pages and live rendering. The pre-redesign baseline and rollback approach are documented in README.md.
