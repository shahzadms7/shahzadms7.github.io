# Product and architecture icon sources

The portfolio reuses its existing local product marks for Microsoft, Azure, AWS, Google Cloud, Kubernetes, Docker, Terraform, Python and other platforms. Original owners retain their marks. Display does not imply endorsement or certification.

Official architecture libraries:

- Microsoft Azure: https://learn.microsoft.com/en-us/azure/architecture/icons/
- AWS: https://aws.amazon.com/architecture/icons/
- Google Cloud: https://cloud.google.com/icons

Official service icons downloaded from the providers' packages on 1 September 2026:

- Azure July 2026 V24: Microsoft Foundry, Azure AI Search, Sentinel, Azure Monitor, AKS, Key Vault, Entra ID and Azure Databricks.
- AWS July 2026: Amazon Bedrock, CloudWatch, Cognito, Lambda and S3.
- Google Cloud core products: Vertex AI and BigQuery.

Packages: [Azure V24](https://arch-center.azureedge.net/icons/Azure_Public_Service_Icons_V24.zip), [AWS July 2026](https://d1.awsstatic.com/onedam/marketing-channels/website/public/shared/architecture-icon-release/Icon-package_07312026.5846e92413caa21490223536cc97f1269e44fa92.zip), [Google Cloud core products](https://services.google.com/fh/files/misc/core-products-icons.zip).

Service icons identify their named products. Provider marks identify broader multi-service groups. Original colours, geometry and proportions are preserved. These are the published source packages available at retrieval time; icon artwork is not evidence of personal production experience.
SVG diagrams embed the local assets so downloaded diagrams do not depend on external image requests. Preserve original icon geometry and colours.
